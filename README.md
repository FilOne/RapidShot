# RapidShot

Компактный скриншотер для **Windows 10/11** с панелью редактирования под снимком. Текущая версия — **1.25.0**.

**[Скачать установщик 1.25 для Windows x64](https://github.com/FilOne/RapidShot/raw/refs/heads/main/releases/1.25.0/RapidShot-Setup-1.25.0-x64.exe)** · [Все релизы](releases/)

## Возможности

- Работа в трее, переключатель автозапуска с Windows и настраиваемая горячая клавиша (**Ctrl + Shift + S** по умолчанию).
- Захват области, отдельного монитора или всех экранов.
- Редактирование области прямо на экране и изменение её границ за края рамки.
- Ручка, линии, стрелки, прямоугольники, эллипсы, текст, размытие и нумерованные пины.
- Плавные стрелки с редактируемыми точками изгиба и одним или двумя наконечниками.
- Лупа: увеличенная копия выбранного фрагмента с обводкой, настройкой масштаба и исходной области.
- Изменение цвета, толщины, прозрачности, положения и размера пометок; отмена и повтор действий.
- Распознавание набросков кругов, эллипсов и стрелок. **Shift** сохраняет пропорции фигур.
- Копирование в буфер, сохранение PNG/JPEG и загрузка на **Yapx** с получением ссылки.
- Обрезка доступна в редакторе полного снимка экрана.
- Оформление: **«Как в системе»**, **«Темный»**, **«Светлый»**. Системный режим автоматически следует теме приложений Windows.

## Использование

Запустите приложение, нажмите **Ctrl + Shift + S** и выделите область. Инструменты появятся под снимком.

Левая часть кнопки **«Захват»** копирует изображение в буфер и подтверждает успех коротким щелчком затвора. Стрелка справа открывает **«Сохранить…»** и **«Загрузить на Yapx»**. Настройки и выбор экрана доступны в меню трея.

**OCR** рядом с «Захватом» распознаёт русский и английский текст и подсвечивает найденные слова на снимке. В поле «Распознанный текст» можно исправить результат и скопировать нужный фрагмент. Кнопка «Копировать» без выделения копирует весь текст. Движок OCR и языковые модели входят в поставку RapidShot и работают локально.

Тема выбирается в **«Настройки → Оформление интерфейса»** и применяется после сохранения без перезапуска.

Автозапуск включается пунктом **«Запускать с Windows»** в меню трея. Галочка означает, что после входа в Windows приложение будет запускаться в трее. По умолчанию автозапуск выключен.

**Стрелка (A):** потяните круглый маркер с плюсом или добавьте точку двойным щелчком по линии. Кнопки **«+»**, **«−»** и **«Прямая»** снизу управляют изгибами.

**Лупа (M):** выделите исходный фрагмент и щёлкните в месте размещения копии. Внизу настраиваются увеличение **1–8×**, цвет и толщина обводки. **«Источник»** показывает рамку для переноса и изменения исходной области.

## Сборка

Требуются **Windows** и **.NET SDK 10**; для установщика — [Inno Setup 6/7](https://jrsoftware.org/isdl.php).

```powershell
dotnet run --project src/RapidShot
./build.ps1 -Portable
./build.ps1 -Installer
```

Результат: `dist/RapidShot/RapidShot.exe` и `dist/Installer/`. Переносимая сборка и установщик включают .NET. Для OCR в переносимой сборке храните папку `ocr` рядом с `RapidShot.exe`. Готовые версии находятся в [`releases/`](releases/).
