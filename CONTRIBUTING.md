# Участие в разработке

Исправления и улучшения приветствуются.

## Ошибки и предложения

Создайте [Issue](https://gitlab.com/whitehillteam/rapidshot/-/issues). Для ошибки укажите версию RapidShot и Windows, шаги воспроизведения, ожидаемый и фактический результат. Для проблем с захватом добавьте число мониторов и масштаб экрана. Скриншоты прикладывайте без личных данных.

## Локальный запуск

Требуются Windows и .NET SDK 10. Для установщика дополнительно нужен Inno Setup 6/7.

```powershell
git clone https://gitlab.com/whitehillteam/rapidshot.git
cd rapidshot
dotnet run --project src/RapidShot
./build.ps1 -Portable
```

`./build.ps1 -Installer` создаёт установщик. Рабочие файлы сборки находятся в `dist/` и `artifacts/`.

## Merge Request

1. Создайте отдельную ветку от актуальной `main`.
2. Сохраняйте изменения в рамках одной задачи и придерживайтесь существующего стиля C#.
3. Проверьте сборку и изменённые сценарии вручную. Для изменений интерфейса приложите скриншот.
4. В Merge Request кратко опишите проблему, решение и выполненную проверку; добавьте ссылку на Issue, если он есть.

Сохраняйте компактность интерфейса. Не добавляйте в коммиты настройки пользователя, секреты, временные файлы и содержимое `bin/`, `obj/`, `dist/`, `artifacts/`. Готовые установщики в `releases/` добавляются при публикации версии.

Изменения принимаются на условиях [лицензии MIT](LICENSE).
